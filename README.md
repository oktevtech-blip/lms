# Loan Management System (LMS)

## Overview

The Loan Management System (LMS) is a web-based application designed to
help organisations manage borrowers, loans, repayments, and reports
efficiently.

## Features

-   Borrower management
-   Loan creation and management
-   Flexible loan durations (Days, Weeks, Months, Years)
-   Payment recording
-   Loan balance tracking
-   Reports
-   User management
-   Settings

## Technology Stack

### Frontend

-   React
-   Vite
-   Tailwind CSS
-   React Router
-   React Icons

### Backend

-   Node.js
-   Express.js

### Database

-   MySQL

## Installation

### Backend

``` bash
cd backend
npm install
npm run dev
```

### Frontend

``` bash
cd frontend
npm install
npm run dev
```
